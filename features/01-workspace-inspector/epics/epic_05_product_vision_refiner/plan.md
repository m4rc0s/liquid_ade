# Plan: Product Vision Refiner & Guided Inception Flow

## Intent
Provide guided elicitation prompts and live document patching for `product_vision.md`, enabling the user to brainstorm, refine the problem statement, target audience, core value proposition, and riskiest assumptions, and apply updates directly to the file.

## Domain Model
- **Terms:** Product Vision, Two-Way Sync
- **Entities:** VisionSection, ElicitationPrompt, VisionDraft
- **Domain events:** VisionFieldRefined, VisionDocumentSaved

## Business Rules
- **R1:** Every refinement proposal generated by the co-pilot must specify the target markdown section in `product_vision.md` before applying.
- **R2:** Applying a vision update must preserve existing comments and unedited sections on disk.

## Examples
- **S1 — Co-pilot prompts for target user definition:** Given a skeleton `product_vision.md`, When the user selects "Refine Target Audience", Then the co-pilot asks guided persona questions and drafts a target persona block.
- **S2 — User approves vision patch:** Given a proposed update for the "Riskiest Assumptions" section, When the user clicks "Apply to Document", Then the server patches `product_vision.md` on disk and the document canvas updates.

## Slices
1. Vision elicitation dialog and direct markdown patcher — S1, S2, R1, R2
